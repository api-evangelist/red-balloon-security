# Red Balloon Security

> Red Balloon Security is an embedded-device and firmware security company protecting critical infrastructure (automotive, aerospace, defense, industrial control, and electrical grid systems). Its public developer surface is OFRAK (Open Firmware Reverse Analysis Konsole), an open-source binary analysis and modification framework distributed as official Python packages. Red Balloon publishes no hosted public REST API; this profile catalogs the OFRAK developer surface.

## Products
- [Firmware Hardening](https://redballoonsecurity.com/): Secures firmware binaries against exploits without source access.
- [Runtime Defense](https://redballoonsecurity.com/): Firmware-level continuous attestation with real-time integrity alerts.
- [OFRAK](https://ofrak.com/): Open-source unpack/analyze/modify/repack framework for firmware and binaries.
- [Bitwise](https://bitwise.co/): FPGA bitstream and binary analysis platform.

## Packages
- [ofrak on PyPI](https://pypi.org/project/ofrak/): pip install ofrak — core platform, CLI, and web GUI.
- [ofrak-type on PyPI](https://pypi.org/project/ofrak-type/): Shared type definitions.
- [ofrak-io on PyPI](https://pypi.org/project/ofrak-io/): Binary I/O primitives.
- [ofrak-patch-maker on PyPI](https://pypi.org/project/ofrak-patch-maker/): Toolchain-driven binary patching.
